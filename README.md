# dolihame 个人博客

基于 React + TypeScript + Tailwind CSS + Vite 构建的个人博客系统。

## 功能特性

- **文章管理** — 创建、编辑、删除文章，支持 Markdown 渲染
- **文章列表** — 卡片式展示，支持搜索和标签筛选
- **文章详情** — 完整 Markdown 渲染，支持代码高亮、表格、引用等
- **标签分类** — 标签云展示，按标签筛选文章
- **关于页面** — 可编辑的个人介绍，支持 Markdown
- **时间轴** — 可视化时间轴，支持添加、编辑、删除事件
- **图片上传** — 文章内嵌图片和封面图片上传（Base64 存储）
- **主题美化** — 8 种预设主题 + 自定义颜色/字体/圆角/卡片样式
- **数据管理** — 导出/导入 JSON 数据备份，一键重置
- **本地存储** — 所有数据保存在浏览器 localStorage

## 技术栈

| 技术 | 说明 |
|------|------|
| React 18 | UI 框架 |
| TypeScript | 类型安全 |
| Tailwind CSS | 原子化 CSS |
| Vite | 构建工具 |
| react-markdown | Markdown 渲染 |
| rehype-highlight | 代码语法高亮 |
| react-router-dom | 路由管理 |
| lucide-react | 图标库 |

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 使用说明

1. **写文章** — 点击导航栏「写文章」按钮，使用 Markdown 编辑器创作
2. **上传图片** — 在编辑器工具栏点击「上传图片」或通过 URL 插入
3. **管理标签** — 在编辑器中添加标签，在「标签」页面查看分类
4. **编辑时间轴** — 在「时间轴」页面添加、编辑成长经历
5. **主题美化** — 点击导航栏「美化」按钮，自定义颜色、字体、卡片样式
6. **数据备份** — 在美化面板的「数据管理」标签页导出/导入数据
